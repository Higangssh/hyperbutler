# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and don't harass anyone. This
applies in issues, pull requests, discussions, and any other project space.

Report unacceptable behavior to the maintainer at sonsanghee3@gmail.com. All reports are
handled confidentially.
