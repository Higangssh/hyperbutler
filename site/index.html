A lightweight, Docker‑compatible engine for Windows — no WSL

hyperbutler boots a minimal Linux VM through the Windows Host Compute Service (HCS, the same API WSL2 uses), runs dockerd inside it, and serves the Docker API on a named pipe. The stock docker CLI talks to it through a hyperbutler docker context.

Why hyperbutler

Docker on Windows usually means Docker Desktop on WSL2. hyperbutler takes another route and aims to work well by default, with no tuning.

  • No WSL needed

    The VM runs directly on HCS. WSL is not required, can stay disabled, and WSL updates do not affect it.

  • Works on Windows Home

    Windows 11 Home is first-class; Pro and Enterprise work too. You need an x64 PC with virtualization enabled in the firmware.

  • Disk space returned automatically

    After deleting 3 GiB of images, the data disk shrank back to within 322–843 MiB of its baseline in 11 s or less, with no manual compaction and no admin step.

  • Small download

    The release zip is about 80 MB, with the docker CLI and the compose plugin included.

  • Fast start

    From hyperbutler start to a working docker info: median 1.44 s (p95 1.45 s, 20 runs, warm host cache).

Numbers are from the README’s Current status, measured on one machine (Windows 11 Home 26200, Core Ultra 7 155H). One machine and one Windows build is not a general result.

Quick start

You need Windows 11 (Home, Pro or Enterprise) on x64, with virtualization enabled in the firmware.

  1. Download and check

    Get hyperbutler-<version>-windows-amd64.msi and SHA256SUMS from the latest release, then compare the hash: 

    Get-FileHash .\hyperbutler-*-windows-amd64.msi -Algorithm SHA256

  2. Install the MSI

    Builds are not code-signed yet, so SmartScreen shows “Windows protected your PC”: choose More info, then Run anyway. The installer asks for one UAC prompt and then:

    • adds hyperbutler and its bundled docker CLI to the end of the system PATH;
    • adds your account to Hyper-V Administrators, if you leave that box ticked;
    • turns on Virtual Machine Platform if it is missing.

    Hyper-V Administrators lets every program you run control the Hyper-V VMs on this PC, not just hyperbutler. Treat it as close to admin rights.

  3. Sign out and back in, or restart once

    The group membership applies after you sign out and back in. If Virtual Machine Platform was turned on, Windows needs a restart.

  4. Run a container

    hyperbutler start
docker run hello-world

Prefer no installer? The zip needs no admin rights for itself; you set up the prerequisites by hand. See the README and docs/install.md.

Preview This is an early preview

It works end to end on Windows 11 Home, but some things are still open. Among them:

  • The 24-hour soak test has not been run (the 1-hour run passed).
  • Until the HCS access broker ships, your account needs Hyper-V Administrators membership.
  • Docker Compose has not been tested yet.
  • Bind mounts from Windows paths work, but are not yet fast for write-heavy trees: use a named volume for node_modules.
  • Builds are not code-signed, and the installer is English only.
